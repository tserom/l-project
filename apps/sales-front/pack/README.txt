销售单（sales-front）— Windows 运行包
================================

无需安装 Node / Go / MySQL。

使用步骤
--------
1. 解压本文件夹到任意目录（路径尽量用英文，避免特殊符号）
2. 双击 start-sales.bat
3. 浏览器会打开 http://127.0.0.1:5175
4. 关闭黑色命令行窗口即停止

若双击后出现乱码或「不是内部或外部命令」
----------------------------------------
请换用最新压缩包（start-sales.bat 已改为纯英文，避免 cmd 编码问题）。

说明
----
- 数据保存在本机浏览器 IndexedDB；清除浏览器站点数据会丢失
- 不同电脑之间数据不共享
- 打印：列表进入「预览打印」→ 打印；建议关闭页眉页脚，边距选默认或最小
- 若提示端口被占用：关闭占用 5175 的程序后重试
